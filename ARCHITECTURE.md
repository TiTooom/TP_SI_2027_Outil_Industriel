# Architecture 

## Frontend

Interface Utilisateur Intuitive
Données en temps réel
Interface Configurable (drag & drop ?)
Gestion des utilisateurs / droits -> création de compte, assigner compte à équipe
Gestion des équipes -> équipe assignée à une interface (affichage mode équipe ou mode perso)

## Backend

Logique métier, config automate, etc
Interaction avec base de données -> lecture / écriture (interdiction écrire sur valeurs capteurs)
Requete frontend

## Base de données 
Structure des informations (schéma relationnel)
Séparation des informations (prod, métier, etc)

## Outils 

HTML, CSS, Javascript, NodeJS, ExpressJS, MariaDB

## Librairies

Bootstrap, ChartJS, Nodemon, Modul Serial, Export-To-CSV, Node-cron, Dotenv
